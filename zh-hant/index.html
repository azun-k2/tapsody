💡 點選上方鍵帽或直接在電腦實體鍵盤上敲擊試聽

透過瀏覽器 Web Audio 即時聲學合成。Mac 應用程式中每次擊鍵均由選單列瞬間觸發。

功能

每次按鍵都會播放一聲由幾個數字當場合成的敲擊聲。App 裡沒有任何錄音，因此體積小巧、一開即用，聽起來也絕不像重複播放的循環。

  • 兩個系列共十七種聲音：七種通用軸體類型，以及十款依據真實鍵盤實測數據調校、模仿整把鍵盤的音色。
  • 聽起來就像真的鍵盤。空白鍵低沉而綿長，Return 鍵和 Delete 鍵比字母鍵更低，鍵盤左側的按鍵聲音從左邊傳來。
  • 隨心調音。在音色板上拖移來調整明亮度和厚度，或使用音調和衰減滑桿。
  • 絕不打擾。可以讓它休眠一陣子、在選定的 App 中靜音，還能看看今天按了多少次鍵。

需要 macOS 14 Sonoma 或以上版本。支援 34 種語言。

錄音取樣軟體與 Tapsody 的對比

為什麼基於物理公式的即時聲學演算法能帶來如同真鍵盤般的自然敲擊感。

特性 錄音取樣工具 Tapsody
延遲 音訊緩衝導致的明顯擊鍵延遲感 按鍵下壓瞬間 0 毫秒即時聲學回應
體積 佔用數百兆空間的龐大 WAV 錄音包 無任何音訊檔案：純物理 DSP 程式碼極為輕巧
聽感 機械重複單一音訊循環，久聽容易疲勞 左右聲道立體聲聲像、真實鍵程與大鍵衛星軸共鳴
智慧靜音 視訊會議和通話時噪音持續干擾 在指定應用程式和視訊會議期間自動休眠靜音
隱私安全 帶有網路連線與按鍵記錄隱患的第三方工具 完全不聯網，且 macOS 系統會自動遮蔽密碼輸入框

一段話說明隱私權

Tapsody 需要「輸入監控」權限，才能知道按鍵何時按下、何時彈起。它只讀取按鍵代碼，其他一概不讀。不儲存任何文字，不傳送任何內容到任何地方，沒有帳號，也沒有網路取用權；在密碼欄位中輸入的內容，macOS 本身就不會交給它。完整的隱私權政策對此有更詳細的說明。
