# Tapsody

Support pages and privacy policy for **Tapsody**, a macOS menu bar app that
plays synthesized mechanical keyboard sounds as you type.

The site is served by GitHub Pages at <https://azun-k2.github.io/tapsody/>:

| Page | URL |
|---|---|
| Home | <https://azun-k2.github.io/tapsody/> |
| Support | <https://azun-k2.github.io/tapsody/support.html> |
| Privacy policy | <https://azun-k2.github.io/tapsody/privacy.html> |

The last two are the support and privacy policy URLs given to App Store
Connect, so their paths should stay put.

Questions and bug reports are welcome in
[Issues](https://github.com/azun-k2/tapsody/issues).

The app's source lives in a separate repository.
